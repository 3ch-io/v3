# 削除・保守管理 (Moderation & Maintenance)

掲示板の秩序を維持するための削除処理、およびデータの復元（ロールバック）に関する仕様。

## 1. 削除処理 (`delete.cgi`)

不適切な投稿やスレッドを管理者が削除するための機能。

### 権限
削除を実行するには、以下のいずれかが必要。
- **掲示板パスワード**: 掲示板作成時に設定したパスワード。
- **キャップ (Cap)**: `cap.cgi` に定義された管理者用キー。
  - `saku`: 削除およびロールバック権限。
  - `sakud`: 削除権限のみ（ロールバック不可）。

### 削除の種類
- **レス単位の削除**: 特定のレス番号を指定して削除（あぼーん化）。
- **スレッド単位の削除**: スレッド全体を削除。
- **一括削除（範囲指定）**: レス番号の範囲（例: 10-20）を指定して一括削除。
- **一括削除（条件一致）**: 特定の文字列を含むレスを一括削除。

## 2. ロールバック (Rollback)

スレッドの状態を過去のバックアップ時点に戻す機能。

- **バックアップファイル**: `back_<key>.cgi` として保存されているデータを使用。
- **制限**: ロールバックを行うと、バックアップ以降の書き込みは完全に消失する。
- **不整合**: ロールバック後、スレッド一覧上のレス数と実際のレス数に乖離が生じることがある（次回の書き込み時に補正される）。

## 3. ログ閲覧

管理者は `delete.cgi` を通じて、通常の閲覧画面では表示されない以下の情報を確認できる。
- 投稿者のIPアドレス、リモートホスト。
- 使用されたユーザーエージェント (UA)。
- 投稿時のセッションIDやキー情報。

## 4. スレッド一覧の保守 (`subject.cgi`)

- `subject.txt` を編集することで、スレッドの順序変更や、特定スレッドの強制的な過去ログ化（行削除）を行う。
