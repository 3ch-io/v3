# 投稿・規制ロジック (Posting & Regulation)

ユーザーからの書き込み処理、およびスパムや荒らしを防ぐための各種規制ロジック。

## 1. 投稿処理 (`bbs.cgi`)

書き込み時に以下の項目がチェック・処理される。

- **必須バリデーション**: 本文の有無、文字数制限、行数制限（`BBS_LINE_NUMBER`）。
- **認証**: 
  - ログイン必須設定（`BBS_BE_ID`）が有効な場合のチェック。
  - 未ログイン時の識別認証用鍵（`WrtAgreementkey`）の使用。
- **二重投稿防止**: `BBS_DUPLICATE` 設定による同一タイトル・同一内容の制限。
- **画像アップロード**: `read.js` 等を介した外部サービス（Imgurなど）へのアップロード連携。

## 2. ID生成と表示 (BBS_SLIP)

ユーザーを識別するためのID生成ロジック。`BBS_SLIP` 設定により挙動が変わる。

- **標準ID**: IPアドレスや日付を元にハッシュ化された文字列（8桁、10桁、16桁など）。
- **KOROKORO**: 接続環境（ISP等）に基づいた特定の文字列を表示。
- **IP表示**: IPアドレスの全部または一部、あるいはリモートホストを表示。
- **県名・回線表示**: `BBS_JP_CHECK` により、IPから判定された地域やISP名を表示。

## 3. 連投・スパム規制 (`BBS_FR_LEVEL`)

`BBS_FR_LEVEL` の値（ビットマスク的な運用）により、以下の規制が組み合わされる。

- **短時間投稿規制**: 前回の投稿から `BBS_FR_SECOND` 秒以内の投稿を制限。
- **連続投稿規制**: 同一スレッド内での連続した書き込みを制限。
- **マルチポスト規制**: 複数のスレッドへの同一内容の書き込みを制限。
- **広域連投規制**: 掲示板全体での短時間の大量投稿を制限。
- **新規連投規制**: 新しく作成されたスレッドへの連投を制限。

### 規制のリセット
`RESET_POSTCOUNT` 設定（10分、1時間、1日など）により、投稿回数のカウントがリセットされる。

## 4. ホスト・環境規制

- **プロキシ規制**: `BBS_PROXY_CHECK` により、公開プロキシ経由の投稿を制限。
- **海外ホスト規制**: `BBS_FOREIGN_PASS` により、日本国外からの投稿を制限。
- **個別規制**: `denylist.cgi` や `rock54.cgi` に登録された特定のホストや文字列を拒否。

## 5. 特殊機能

- **スレッド作成主 (NUSI)**: `BBS_DISABLE_NUSI` が無効（＝有効）な場合、スレ立て主が特定の管理権限を持つ。
- **コマンド機能 (VIPQ2)**: 本文1行目に `!extend` などのコマンドを記述することで、そのスレッド固有の設定（ID表示の有無など）を変更できる。
- **実況モード**: `LIVE_THREAD` が有効な場合、連投規制が緩和される。
