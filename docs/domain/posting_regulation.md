# 投稿・規制ロジック (Posting & Regulation)

ユーザーからの書き込み処理、およびスパムや荒らしを防ぐための多層的な規制ロジック。

## 1. 投稿処理フロー (`bbs.cgi`)

書き込みリクエスト（POST）を受け取ると、以下の順序でチェックが実行される。

### 1.1 初期接続チェック
- **メソッド制限**: POSTメソッド以外は拒否。
- **Ruthless Angel (残酷な天使)**: 短時間に多数の書き込みエラーを発生させたIPアドレスを一時的に完全封鎖する。
  - 判定条件: `BBSSERV/<日番号>/403_<IPアドレス>.cgi` ファイルの存在。
- **UA制限**: 特定の専ブラ（JaneStyle, BB2C, mae2c等）や、異常に長いUA、マルチバイト文字を含むUAを制限。

### 1.2 コンテンツ・バリデーション
- **文字コード**: UTF-8からShift_JIS(SJIS-win)への変換。絵文字は数値実体参照化。
- **不正文字**: ヌル文字や特定の制御コード（`&#0?10;`, `&#x[xX]0?a;` 等）を含む投稿を拒否。
- **サニタイズ**: 名前・メール・本文のHTMLタグ無効化、偽キャップ（★）や偽トリップ（◆）の置換。
- **必須チェック**: 本文の有無。

### 1.3 認証・アカウント
- **Googleログイン**: `Use_Account` 有効時、クッキーの `secretkey` を確認。
- **アカウントBAN**: スパム判定されたアカウント（`BAN_<key>.cgi`）を日付が変わるまで規制。
- **認証要求**: 未ログインかつ専ブラ以外からの投稿時、CAPTCHA（reCAPTCHA）認証を要求。

## 2. 書き込み規制の詳細ロジック

エラーメッセージごとに、発動条件とロジックを以下に分類する。

### 2.1 時間・頻度による規制
- **Samba24 (短時間連投)**:
  - `BBS_FR_SECOND` 秒以内の再投稿を制限。
  - 警告を無視して投稿を続けると「Violation」となり、約1時間の書き込み禁止に移行する。
- **We hate Continuous (広域連投)**:
  - 同一IPグループ（`/16` や `/24` 等）からの連続投稿を検知。
  - `!live` コマンドが設定されていないスレッドで発動しやすい。
- **投稿数制限**:
  - 掲示板全体またはスレッド単位での短時間内の投稿上限数（`timecount`, `timeclose` 等の設定）を超えた場合に発動。

### 2.2 内容・属性による規制
- **CoPiPe (コピペ規制)**:
  - 直近の他のレスと類似性が高い文章の投稿を制限。
- **NGワード規制**:
  - `SETTING.TXT` や `denylist.cgi` に基づく。
  - 強度により「投稿拒否」または「👀（目）が付与される」等の段階がある。
- **PHOEBE (レベル規制)**:
  - モバイル回線や公衆Wi-Fi利用者が対象。
  - **レベル計算**: 初回アクセスからの経過時間で決定。
    - ~600s: Lv0 / ~3600s: Lv1 / ~18000s: Lv2 / ~82800s: Lv3 / 以降23時間ごとに+1（最大40）。
  - **判定**: スレッドに設定された必要レベル（`!SETTING:BBS_PHOEBE:n`）に満たない場合、投稿不可。

### 2.3 ホスト・環境規制
- **BBX規制**: Proxy、VPN、過去の荒らしホストを対象としたピンポイント規制。
- **海外ドメイン規制**: `BBS_FOREIGN_PASS` 有効時、日本国外からの投稿を制限。
- **プロキシ規制**: `BBS_PROXY_CHECK` により、公開プロキシを検出して遮断。

## 3. ID生成と表示 (BBS_SLIP)

`BBS_SLIP` 設定と接続ホスト名に基づき、名前欄のニックネームとIDが生成される。

### ホスト判定とニックネーム例
- **docomo (spmode)**: ｽﾌﾟｯｯ, ｽｯﾌﾟ, ｽｯｯﾌﾟ 等
- **au (au-net)**: ｱｳｱｳｱｰ, ｱｳｱｳｳｰ, ｱｳｱｳｶｰ 等
- **SoftBank (panda-world)**: ｻｻｸｯﾃﾛﾗ, ｻｻｸｯﾃﾛﾘ 等
- **MVNO/その他**: ｵｯﾍﾟｹ, ﾌﾞｰｲﾓ, ﾃﾃﾝﾃﾝﾃﾝ, ﾜｯﾁｮｲ 等

### 表示形式 (`!extend` コマンド等)
- **vvv**: 識別ID（日替わり）。
- **vvvv**: IPアドレス表示。
- **vvvvv**: KOROKORO（10日ごとに変化するニックネーム）。
- **vvvvvv**: IPアドレス + KOROKORO。

## 4. 特殊コマンドによる動的設定

本文1行目に記述することで、スレッド単位の規制を上書きできる。
- `!extend:<ID表示>:<SLIP表示>:<最大レス数>`
- `!jien`: ID強制表示 + 識別ID表示（自演防止モード）。
- `!バルサン`: PHOEBEレベル2以下を排除。
