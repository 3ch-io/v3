# クライアントサイド機能 (Client-side Logic)

ブラウザ上で動作するJavaScriptによる、動的な閲覧体験やユーザー設定に関する仕様。

## 1. 動的レンダリングと取得 (`read.js`, `read-v1.js`)

HTMLモードにおいて、スレッドデータの取得と描画を行う。

- **データ取得**: `XMLHttpRequest` を用いて `/<bbs>/dat/<key>.dat` を取得し、行単位でパースする。
- **インライン表示**: レスアンカー（`>>1`）へのマウスオーバー時に、該当レスの内容をポップアップ表示する。
- **画像プレビュー**: 本文内の画像URLを検出し、サムネイル表示やライトボックス（拡大表示）機能を提供する。

## 2. フィルタリング機能 (NG機能)

ユーザー個別の判断で特定の投稿を非表示にする機能。設定はブラウザの `localStorage` に保存される。

- **IDミュート**: 特定のIDを持つユーザーの投稿を「あぼーん」にする。
- **ワードミュート**: 特定の文字列を含む投稿を非表示にする。
- **タイトルミュート**: 特定の文字列をタイトルに含むスレッドを一覧から除外する。

## 3. 自動更新と通知 (`active.js`)

- **自動更新**: 設定された間隔（デフォルト5秒など）でサーバーに新着レスの有無を確認し、差分をスレッド末尾に追加する。
- **通知**: 新着レスが発生した際、画面上に通知を表示し、新着位置へのスクロールを促す。
- **ページ遷移なしの投稿 (AJAX投稿)**: フォーム送信を非同期で行い、ページをリロードせずに書き込みを完了させる。

## 4. 表示設定とカスタマイズ

`localStorage` を使用して、以下のユーザー設定を保持する。

- **ダークモード**: デバイスの設定との同期、または手動切り替え。
- **ツリー表示**: レスアンカーの構造に基づいた階層的な表示。
- **自動スクロール**: 新着レス取得時に自動的に最下部へスクロールする。
- **閲覧モードの記憶**: CGIモードとHTMLモードのどちらを優先するか。

## 5. タイムライン表示 (`timeline.js`)

- `timeline.json` から複数の板やスレッドを横断した最新の投稿を取得し、時系列順に表示する。

## 6. デバイス最適化

- `isSmartPhone()` 関数により、ユーザーエージェントや画面幅からモバイル環境を判定し、UI（ボタン配置やフォームの固定など）を最適化する。
