# スレッド閲覧・取得 (Thread Viewing & Retrieval)

スレッドの表示、データの取得、およびスレッドの寿命（dat落ち）判定に関する仕様。

## 1. 閲覧モード

3ch-v3には、サーバーサイドレンダリングとクライアントサイドレンダリングの2つの主要な閲覧モードが存在する。

### CGIモード (`read.cgi`)
- サーバー側でPHPがスレッドデータを解析し、HTMLを生成して返す。
- 検索エンジン（bot）やJavaScript無効環境向けのフォールバックとしても機能する。
- ページ分割（100レス単位など）や「最新50」などの表示範囲指定に対応。

### HTMLモード (`read_html.cgi` + `read.js`)
- サーバーは外枠のHTMLのみを返し、実際のデータはJavaScript（`XMLHttpRequest`）で `.dat` ファイルから取得してクライアント側で描画する。
- より動的な操作（自動更新、インライン返信表示など）が可能。
- `read.cgi` への切り替えボタンを提供。

## 2. データ構造と取得

### データ形式
- スレッドデータは `/<bbs>/dat/<key>.dat`（または `.cgi`）に保存される。
- 各レスは1行で構成され、項目は `<>` で区切られる。
- **主要項目**: 名前, メールアドレス, 日付/ID, 本文, スレッドタイトル（1レス目のみ）, 各種メタ情報（シリアライズされた配列）。

### 部分取得 (`get_res.cgi`)
- 新着レスの差分取得などに使用される。
- URLパラメータ（`l50`, `1-100`, `100-` など）により、取得範囲を制御する。

## 3. スレッドの寿命と停止判定 (dat落ち)

スレッドへの書き込み可否は、以下の条件に基づいて判定される。

- **最大レス数超過**: `LINENUM >= SETTING[MAX_RES]`。
- **手動停止**: `SETTING[THREAD_STOP] == "yes"`。
- **即死判定**: スレッド作成から一定時間 (`TIME_TO_LIVE`) 経過しても、規定レス数 (`BBS_TH_LINE`) に達していない場合。
- **突然死判定**: 最終更新から一定時間 (`BBS_MAX_MODIFIED`) 更新がない場合（主に実況板などで適用）。
- **絶対寿命**: スレッド作成からの経過時間が `BBS_THREAD_LIFETIME` を超えた場合。
- **一覧からの消失**: `subject.txt` から該当スレッドの行が削除された場合。

## 4. 特殊な表示ロジック

- **あぼーん表示**: 削除フラグ（`del`）が立っているレスや、クライアント側のNG機能に合致したレスを「あぼーん」として隠蔽する。
- **レスアンカー変換**: `>>1` などの記述をリンクに変換し、ホバー時やクリック時に該当レスを表示する。
- **名前の色付け**: バレンタインデー（02/14）などの特定日や、設定されたデフォルトの色に基づき名前の色を変更する。
