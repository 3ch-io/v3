# 検索・発見機能 (Search & Discovery)

掲示板内のスレッドやレスを検索し、新しいコンテンツを発見するための機能。

## 1. 本文検索 (`find.cgi`)

掲示板全体のレス本文を対象とした検索機能。

### 検索演算子
- **スペース**: AND検索（両方の単語を含む）。
- **OR**: OR検索（どちらかの単語を含む）。
- **NOT**: 除外検索（その単語を含まない）。
- **@<板名>**: 特定の板（板IDまたはタイトル）に限定して検索。
- ***<スレッド名>**: 特定のスレッド（スレッドkeyまたはタイトル）に限定して検索。

### 仕様
- 検索結果は最大300件まで表示。
- `find.txt` ログファイルを元に検索を行う。

## 2. スレタイ検索 (`search.cgi`)

スレッドのタイトルを対象とした検索機能。

### 勢い (Momentum) の計算
検索結果一覧において、スレッドの「勢い」が計算・表示される。
- **計算式**: `(レス数 / スレッド作成からの経過秒数) * 86400`
- 1日あたりのレス数に換算して表示される。

### 仕様
- 検索結果は最大1000件まで表示。
- `threads.txt` ログファイルを元に検索を行う。

## 3. ハッシュタグ機能 (`hashtag.cgi`)

本文中に含まれるハッシュタグ（`#単語`）を抽出し、同じタグを持つレスを一覧表示する機能。

## 4. おすすめスレッド機能 (Recommendation)

閲覧履歴に基づき、「このスレッドを見ている人はこんなスレッドも見ています」を表示する。

### ロジック
- ユーザーがスレッドを閲覧すると、クッキー（`b`）に閲覧情報が保存される。
- サーバー側では `/tmp/<bbs><日番号>/b_<hashtag>.cgi` などの一時ファイルに、同一ハッシュタグや同一板内での併読情報を蓄積する。
- 蓄積されたデータから直近の5件程度を抽出して表示する。

## 5. 板一覧・メニュー (`bbsmenu.cgi`)

- システム内の全掲示板をカテゴリ別に一覧表示する。
- 各カテゴリのデータは `etc5.cgi`, `news.cgi`, `society.cgi` などの定義ファイルから読み込まれる。
